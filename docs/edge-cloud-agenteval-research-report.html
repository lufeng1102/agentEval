一句话结论：现有 LLM / Agent 评测框架已经覆盖 agent 轨迹、工具调用、在线/离线评估、生产监控、延迟、token 和成本等云侧或应用侧维度；但通常没有把移动端、IoT/边缘设备、本地模型 + 云模型混合、端侧能耗、端侧隐私预算作为一等公民。

1. 生态分层

LLM / Agent 行为评测框架

代表项目包括 AgentEval、OpenAI Evals、LangSmith、DeepEval、Ragas、Inspect AI、Azure AI Evaluation、Google Vertex AI Eval。

  • 任务完成度
  • 工具调用准确性
  • RAG 质量
  • 安全性
  • trajectory / trace
  • latency / token / cost

边缘 / 端侧 ML 性能基准

代表体系包括 MLPerf Tiny、MLPerf Edge、EdgeBench 等。它们更适合评估设备、模型和硬件性能。

  • 端侧推理性能
  • 硬件吞吐
  • 端侧延迟
  • 能耗
  • 资源约束
  • 嵌入式 / IoT 场景

3. 关键发现

主流 AgentEval 框架没有把“端云融合”作为核心对象

OpenAI Evals、Inspect AI、DeepEval、Ragas 等支持 LLM 系统评估、agent、tool-using agents、tracing 和 custom evaluator，但公开文档中没有把 mobile、IoT、edge-cloud collaboration、本地模型 + 云模型协同、端侧能耗、电量、热限制、NPU / CPU / GPU 利用率、弱网 / 离线降级、端侧隐私预算作为内建评测对象。

Microsoft Foundry / Azure AI Evaluation 是商业平台中最接近的方案

它覆盖 agent evaluator、tool call accuracy、task completion、intent resolution、tracing、production monitoring、latency、token consumption、error rate、quality score、CI/CD quality gate、Application Insights、distributed tracing 和企业隔离能力。但它仍不是“端云融合 Agent 评测框架”。

LangSmith、DeepEval、Inspect 更适合作为上层 Agent 行为评测层

这些框架可以评估 agent 是否完成任务、工具是否选对、RAG 是否 grounded、hallucination 是否降低、safety 是否合规、trace 是否符合预期、latency / cost 是否达标。但如果要评测端云系统，需要用户自行把端侧日志、设备指标、云侧调用和协同决策建模为 dataset、trace 或 evaluator。

边缘基准与 AgentEval 是互补关系

MLPerf Tiny / Edge、EdgeBench 更适合评估模型在设备上的推理性能、吞吐、资源和能耗；但通常不评估 Agent 是否完成任务、是否正确选择工具、是否正确进行本地/云端路由。

4. 当前空白点

跨层 trace schema

缺少同时描述 device / cloud / hybrid 执行位置、模型来源、网络状态、隐私边界、端侧资源和云侧调用的统一 trace schema。

端云路由决策评估

缺少评估“何时本地执行、何时升级云端、何时弱网降级、何时出于隐私留在端侧”的内建 evaluator。

真实设备环境指标

缺少 energy per successful task、电量、热限制、内存压力、NPU 利用率、弱网质量下降、PII 上传率等标准指标。

5. 建议的 AgentEval 扩展路线

建议方向：不要从零重写，而是在现有 AgentEval 数据流上扩展为“端云协同 trace + 多维 evaluator”。 
Dataset YAML + Config YAML
  -> Device / Cloud / Hybrid AgentAdapter
  -> AgentRun + EdgeCloudTrace
  -> Behavior Evaluators
  -> Tool Evaluators
  -> Routing Evaluators
  -> Device Metric Evaluators
  -> Privacy Evaluators
  -> Cost / Latency / Energy Evaluators
  -> JSON / Markdown / HTML report
